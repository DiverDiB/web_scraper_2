# Python Web Scraper

A web crawler and scraper built in Python as part of the [Boot.dev](https://www.boot.dev) curriculum. It parses HTML pages, normalizes URLs, extracts links and page text, and structures data cleanly.

## Requirements
- Python 3.x
- Beautiful Soup (`beautifulsoup4`)

## Running Tests
To run the test suite, execute:
```bash
uv run -m unittest discover
# or python3 -m unittest
